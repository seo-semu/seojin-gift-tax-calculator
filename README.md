# 증여세 계산기

서재혁 세무사의 증여세 계산기입니다. 현행 「상속세 및 증여세법」 기준으로 계산합니다.

- 관계별 증여재산공제, 10~50% 누진세율, 신고세액공제
- 10년 내 재차증여 합산과 납부세액공제 자동 계산
- 조부모 증여(세대생략) 할증 30%·40%
- 혼인·출산 증여재산공제, 비거주자
- 증여세 대납(그로스업) 계산
- 받는 사람을 나눠 줄 때의 세액 비교
- 부담부증여(주택): 증여세와 채무 인수분 양도세 비교

검증: `node tests/verify_gift.js`

계산 결과는 참고용이며, 정확한 판단은 세무 전문가와 상담하시기 바랍니다.
